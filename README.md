## Overview

FabFilter One is a clean, elegant monophonic synthesizer with a single oscillator, ladder filter, and simple modulation delivering exceptional analog-style sound in a minimal interface.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FabFilter One** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Clean Oscillator** | Single oscillator with pulse, sawtooth, and noise waveforms |
| **Ladder Filter** | Four-pole resonant low-pass filter with warm analog character |
| **Modulation** | Two LFOs and two envelopes with freely assignable destinations |
| **Vintage Character** | Subtle non-linearity models the imperfection of analog circuits |
